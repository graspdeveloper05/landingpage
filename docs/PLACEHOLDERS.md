### Checking what is left

```bash
npm run check:placeholders     # report
```

`npm run predeploy` runs the same check with `--ci` and **exits non-zero** while
any placeholder remains. Wire that into your deploy pipeline and fabricated
people cannot reach production by accident.

To regenerate after changing anything in `frontend/art/`:

```bash
npm install --no-save sharp
node frontend/scripts/optimise-images.mjs
```

sharp is deliberately not in `package.json`: the cPanel deploy runs `npm ci` on
a shared host, and a binary dependency there would risk failing the whole build
for a step that only runs when artwork changes.

**Note on the logo:** it was supplied as a JPEG-style card with no alpha
channel, so the cream ground is baked in. On the ivory header the emblem uses
`mix-blend-multiply` to drop that ground; on the navy footer it sits on a light
plate instead, because multiply would erase it. A transparent PNG or SVG of the
logo would remove the need for either trick.
