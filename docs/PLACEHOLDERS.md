### Checking what is left

```bash
npm run check:placeholders     # report
```

`npm run predeploy` runs the same check with `--ci` and **exits non-zero** while
any placeholder remains. Wire that into your deploy pipeline and fabricated
people cannot reach production by accident.

| `src/i18n/locales/*.json` → `about.*` | Description of the Dialogue and its long-term ambition |
| same → `theme.*` | The 2026 theme wording, its four key questions, and the pull quote |

Locale files are generated. Edit `scripts/build-locales.mjs` and re-run
`node scripts/build-locales.mjs` rather than editing the JSON by hand — that is
what keeps all four languages at identical keys.
