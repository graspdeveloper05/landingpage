# Progress Report — 10 September 2026

**Project:** Seri Negara Dialogue 2026 (serinegaradialogue.org)
**Stack:** React + Tailwind (frontend) · Laravel (backend) · single domain on cPanel
**Commits today:** 30

---

## 1. Frontend and backend are now connected

The website used to hold its own content in files in the code. It now reads
everything from the Laravel backend, and both run on **one domain** — no
separate API address to buy, secure or explain.

- Speakers, programme, event details and registrations all live in the database
- Laravel serves the React site; `/api/...` stays the API
- Registrations save to the database and send a confirmation email

---

## 2. Admin panel — the organising team can edit the site themselves

Built at **/admin**. No developer needed for routine content changes.

| Section | What the team can do |
|---|---|
| Event | Change date, time, venue and seat capacity |
| Speakers | Add, edit, remove, reorder |
| Programme | Add, edit, remove, reorder sessions |
| Registrations | See every RSVP, download as CSV |
| Analytics | Visitors, page views, where they came from |

**Registration states** — the form now knows *why* it is closed, and says so:
open · closed by hand · event has passed · all 200 seats taken.

**Login:** `admin@serineg.com` / `admin@123`
⚠️ This is the default and is written in the code. **Change it before handover.**

---

## 3. Analytics (brief §12)

Added our own visitor counting — **no Google, no cookies, no consent banner**.
Nothing leaves the server, so there is no privacy notice to add.

---

## 4. Design and polish

- **Share card** — the picture that appears when the link is sent on WhatsApp,
  Facebook or LinkedIn. Built to match the site, not a generic screenshot.
- **Site icon (favicon)** — the arch mark, drawn so it still reads at 16px.
- **Custom cursor** — a small dot with a gold ring that opens over anything
  clickable. Switched off on phones, for anyone who has asked for reduced
  motion, and inside text fields.
- **Admin sign-in screen** redesigned, with a show/hide password control.
- **Loading states** — real skeletons and a progress bar instead of "Loading...".
- **Toast messages** — saves confirm at the bottom of the screen, so a save made
  at the foot of a long form no longer looks like it did nothing.
- **Motion** (Framer Motion) — the sidebar marker slides between sections,
  toasts settle into place, buttons and rows answer the pointer.

---

## 5. Deployment

`bash deploy.sh` now rebuilds and publishes both halves on cPanel in one step.
Several failures were found and fixed today:

- Composer not found on the server → it now finds cPanel's own copy
- Site returned a 500 error on first deploy → the app key is generated and
  **the site is checked that it actually boots before it is published**
- The deploy log showed old errors as if they were new → now filtered by time

---

## 6. Security

- Removed a stock Laravel account (`test@example.com` / `password`) that would
  have been a working back door into the full attendee list
- Fixed a bug where adding admin login had silently broken **every public
  registration** — caught and repaired the same day
- The Laravel application stays outside the public folder, so the database
  password and mail password cannot be downloaded
